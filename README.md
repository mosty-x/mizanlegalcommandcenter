# ميزان — المسارات القانونية المصرية ٢٫١

إصدار تنفيذي جديد من تطبيق ميزان المجهز للنشر على رايلواي. يحتوي خمسة مسارات تعتمد على ذاكرة قانونية مقيدة بالمصادر، وتضمين دلالي، وإعادة ترتيب عصبية، وفحص اقتباسات، ومراجعة مستقلة للاستنتاجات.

**الحزمة لا تحتوي قاعدة كاملة للقانون المصري أو اشتراكات أو مفاتيح.** تبدأ الذاكرة فارغة، وتمتنع عن إصدار نتيجة بلا سند. التشغيل الحقيقي يحتاج خدمات الذكاء التي تختارها ونصوصًا مصرية مراجعة ومرخصة. الاختبارات الاصطناعية تثبت سلوك الكود، ولا تثبت الدقة القانونية.

## أول تشغيل على رايلواي

1. فك الحزمة وارفع محتويات هذا المجلد إلى مستودعك. ملف بناء الحاوية وإعداد النشر موجودان في الجذر.
2. اربط الخدمة بالمستودع، واستخدم نسخة تشغيل واحدة ومساحة تخزين دائمة مركبة عند المسار التالي:

```
/data
```

3. حافظ على مفاتيح النسخة السابقة لو عندك بيانات موجودة. لا تغيّر مفتاح التشفير عند ترقية قاعدة البيانات.
4. اضبط متغيرات الاستضافة الموضحة في ملف المثال. أنشئ مفتاحين عشوائيين مختلفين بطول ٣٢ بايت بترميز بيس٦٤. متغير مسار البيانات:

```
DATA_DIR=/data/mizan
TERMS_VERSION=2026-09-10-rag-v2
```

المتغيران السريان:

```
CREDENTIAL_MASTER_KEY
SESSION_SIGNING_KEY
```

5. افتح المنصة وأكمل الدليل. من الإعدادات سجّل خدمات التحليل والتضمين وإعادة الترتيب والمراجعة في الخزنة.
6. افتح «الذاكرة القانونية المصرية»، وحدّد المصادر التي يستخدمها مكتبك، واختر خدمات كل وظيفة، ثم استورد النصوص بعد مراجعتها.
7. افتح «تطوير التخصص والمراجعة» لتعديل تعليمات كل أداة وتركيز بحثها ونصوصها الإلزامية وميزانية السياق. كل حفظ ينشئ إصدارًا مستقلًا، ويمكن مقارنة القديم واستعادته بإصدار جديد.
8. افتح الأداة، وارفع مستندات المهمة، وحدد التاريخ القانوني وقواعد التحكيم المتفق عليها، وشغّل المسار.

## التشغيل المحلي

تحتاج نسخة نود ٢٤ أو أحدث. الأمر التالي ينشئ ملف إعداد محلي بمفاتيح جديدة إذا لم يوجد ملف سابق، ولا يطبع الأسرار:

```bash
npm ci
node scripts/create-env.mjs
npm run dev
```

للبناء والتحقق:

```bash
npm test
npx tsc --noEmit
npm run build
npm run smoke
```

اختبار التشغيل يستخدم خدمات ذكاء اصطناعية بديلة وبيانات مصطنعة، وينفذ المسارات الخمسة عبر الشبكة الداخلية وكذلك عبر اتصال تجريبي مثبت البصمة بالسيرفر.

## حدود التشغيل الحالية

- تخصيص التوجيه لا يدرّب أوزان الموديل ولا يثبت زيادة الدقة. التعديلات تحتاج تقييمًا على عينة مراجعة قبل تعميمها.
- عزل البيانات هو عزل مساحة الزائر الموقعة والمستندات المحددة والأداة. ليس نظام حسابات مؤسسية أو صلاحيات شركاء وفِرق. فقد ملف الارتباط لا ينقل بياناتك تلقائيًا لمساحة جديدة.
- أقصى ذاكرة للمستخدم ٥٠٠ وحدة، واستيراد ٢٠٠ وحدة في الطلب. لكل وحدة حد نص واضح؛ قسّم النص حسب المادة أو الفقرة دون حذف الاستثناءات والإحالات المهمة.
- ٨ مستندات في التشغيل، وبحد ١٤٠ ألف حرف و٤٢ مقتطفًا. تجاوز الحد يوقف التشغيل؛ لا يجري تحليل جزئي صامت في النسخة الجديدة. المستندات القديمة التي قُصت في النسخة السابقة تحتاج إعادة رفع.
- لا يوجد تعرف بصري على الصور أو حساب تلقائي للمواعيد القانونية. الملفات المصورة تحتاج استخراج نص موثوق ومراجع قبل إدخالها.
- المصادر القانونية لا تُجلب آليًا أثناء التحليل. الاستيراد والمراجعة والسحب صريحون. عناوين المصادر وحدها لا تثبت مطابقة النص المستورد للموقع.
- فحص الاستنتاج بواسطة موديل آخر ليس حكمًا قانونيًا ولا ضمانًا ضد الخطأ. بعض أخطاء النماذج قد تمر؛ المراجعة البشرية وقياس الأداء على ملفات المكتب لازمان.
- سجل الخطوات محفوظ، لكن استئناف خطوة بعد تعطل العملية ليس مدعومًا. إعادة التشغيل تعيد التحليل وتستفيد من ذاكرة التضمين والترتيب الصالحة.
- انتهاء اتصال السيرفر لا يثبت توقف عمله فورًا. المستقبل المرفق يفرض مهلة مستقلة. لا تُنفذ إجراءات قانونية أو أوامر حرة.
- النسخة القديمة من بروتوكول السيرفر لا تكفي للمسارات الجديدة؛ اتبع دليل الترقية المرفق. لا يوجد رجوع تلقائي إلى التحليل القديم.
