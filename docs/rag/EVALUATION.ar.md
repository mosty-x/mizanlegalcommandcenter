# التقييم قبل استخدام ملفات عمل حقيقية

الاختبارات الحالية تتحقق من منطق العزل والبوابات والتشغيل بعينات اصطناعية وخدمات بديلة. لا يوجد في الحزمة رقم دقة قانونية أو ادعاء بتقييم محامٍ أو نجاح خدمات فعلية بمفاتيح المستخدم.

جهز عينة مصرية يراجعها محامٍ، تشمل لكل أداة ملفات عادية وحالات يجب الامتناع فيها. قسّم العينة إلى معايرة واختبار نهائي، ولا تغيّر الحد بعد رؤية نتائج الاختبار النهائي.

| القياس | ما نحتاجه |
|---|---|
| استرجاع السند الصحيح | معرفات النصوص التي اختارها المحامي مقابل النصوص المسترجعة؛ قياس الاستدعاء وجودة الترتيب |
| سلامة الاقتباس | مطابقة النص والنسخة والموضع، لا وجود معرف فقط |
| سلامة الاستدلال | هل تؤيد الأدلة كامل الادعاء والاستثناءات والتطبيق؟ حكم بشري لكل عنصر |
| الامتناع الصحيح | ملفات غير كافية أو خارج الاختصاص، مع رصد الإجابات غير المسموحة والامتناعات الزائدة |
| التعامل مع التعديلات | نص نافذ وملغى ومعدل وتعارض تواريخ؛ لا اختيار تلقائي لنسخة متعارضة |
| السرية | فصل مستخدمين وأدوات وملفات، وسحب المصدر وإبطال النتائج والتخزين |
| الكلفة والزمن | الزمن الكلي وزمن كل خطوة، عدد طلبات التضمين والترتيب والتوليد، والرموز التي يبلغها المزود |

لا يمكن قياس جودة استدلال قانوني من نجاح اختبارات مخططات البيانات. ولا تعد نتيجة المراجع الآلي مرجعًا ذهبيًا لتقييم نفسه.

أمر تقييم ترتيب الاسترجاع، بعد أن تعبئ بيانات مراجعة حقيقية:

```bash
node scripts/evaluate-retrieval.mjs your-reviewed-results.json
```

لكل حالة أدخل معرفات المصادر المرجعية والمسترجعة. المقيّم يرفض مجموعة فارغة؛ لا يحسب نسبة نجاح من بيانات مفقودة. قالب البنية موجود مع أمثلة الإعدادات.

التجربة البرمجية تختبر أربع مكالمات توليد في التشغيل المعتاد، وتختبر الأدوات الخمس كمنتجات مستقلة عبر واجهات الخدمات وعبر السيرفر البعيد. جميع بياناتها مصطنعة وغير قابلة للاستخدام كسند. لا تتضمن هذه النسخة فحص اختراق مستقلًا أو تأهيلًا قانونيًا أو اختبار ضغط بأحجام مكتب كامل.
