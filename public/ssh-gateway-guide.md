# تشغيل المسار المصري الكامل على سيرفرك

هذه ترقية لمحرك السيرفر نفسه. مفاتيح الدخول وحدها لا تثبّت برنامجًا على السيرفر. يجب نقل الريبو إلى السيرفر مرة واحدة وتجهيز المستقبل التالي؛ بعدها يستقبل المهمة وينفذ الاستخراج والبحث وإعادة الترتيب والتحليل والمراجعة كاملة.

## ١. تثبيت المستقبل

المثال لسيرفر لينكس تملكه، عليه نود ٢٤، وحساب خدمة ومجموعة باسم ميزان. اضبط المسارات والحساب بمعرفة مسؤول السيرفر. لا تستخدم حساب المدير العام لتشغيل التحليل.

ضع محتويات الريبو في المسار التالي، وثبّت الاعتمادات بما فيها مشغّل تايب سكريبت:

```bash
cd /opt/mizan
npm ci --include=dev
sudo install -d -m 750 -o root -g mizan /etc/mizan
sudo install -d -m 700 -o mizan -g mizan /var/lib/mizan-receiver
sudo install -m 640 -o root -g mizan ssh-server/egypt-receiver.example.json /etc/mizan/receiver.json
sudo install -m 640 -o root -g mizan ssh-server/receiver.env.example /etc/mizan/receiver.env
sudo install -m 755 ssh-server/mizan-workflow-wrapper.sh /usr/local/bin/mizan-workflow
sudoedit /etc/mizan/receiver.json /etc/mizan/receiver.env
```

المثال يحتوي بدائل نصية، وليس مفاتيح صالحة. ضع مفاتيح خدمات التحليل والتضمين وإعادة الترتيب والمراجعة في إعداد المستقبل. أنشئ مفتاحي تشفير وتوقيع مختلفين، كل منهما ٣٢ بايت عشوائية بترميز بيس٦٤، في ملف البيئة. احتفظ بهما عند التحديث. استخدم مسارًا دائمًا للبيانات وحدد أسماء خوادم الخدمات المسموحة فقط.

القيم الخاصة بالخدمات تبقى على سيرفرك. مصنّف المزود المتوافق يدعم مسار التضمين المتوافق مع أوبن إيه آي، ومسار إعادة الترتيب المتوافق مع كوهير. الموديلات المذكورة في المثال بدائل نصية؛ راجع دعم العربية وحجم السياق عند مزودك. دليل الربط موجود بالحزمة داخل مجلد docs/rag.

## ٢. تقييد الدخول

أضف المفتاح العام المخصص إلى حساب الخدمة مع الأمر الثابت:

```text
restrict,command="/usr/local/bin/mizan-workflow --stdio" ssh-ed25519 YOUR_PUBLIC_KEY
```

استخرج بصمة مفتاح المضيف من شاشة إدارية موثوقة:

```bash
sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256
```

ضع البصمة والعنوان والمنفذ واسم المستخدم والمفتاح الخاص وكلمة سر المفتاح في «مزود تنفيذ عبر سيرفر». أضف العنوان نفسه والمنفذ إلى بيئة منصة رايلواي:

```env
ALLOWED_SSH_HOSTS=your-server.example:22
```

المسموح عنوان ومنفذ بالضبط، والعميل يستخدم اتصال آي بي الإصدار الرابع. البصمة إلزامية. لا يكفي أخذ بصمة من قناة غير موثوقة. الأمر ثابت ولا يقبل أوامر من المستندات أو الواجهة. خانة اسم ملف التشغيل باقية للتوافق مع المزود القديم؛ المحرك المصري المرفق يحدد المسار من معرف الأداة ولا يستخدمها لتشغيل ملفات اختيارية.

## ٣. سياسة الذاكرة على المنصة

حتى عند تشغيل التحليل كله على السيرفر، تختار المنصة النصوص المسموحة وفق سياسة المكتب. استخدم ملف المثال التالي بعد مراجعة المصادر وتأكيد استخدامها:

```
public/examples/rag-policy-ssh.json
```

ارفعه من الإعداد والتخصيص كسياسة الذاكرة. معرفات الخدمات فيه أسماء ربط وصفية؛ فرع السيرفر لا يبحث عن مفاتيحها في خزنة المنصة. الإعداد الفعلي للخدمات الأربع هو إعداد المستقبل على السيرفر. لا ترسل أسرار هذه الخدمات داخل ملف سياسة المكتب. لا تحتاج إنشاء مزودات محلية وهمية.

زر اختبار السيرفر يتحقق من الاتصال والبصمة والمستقبل وشكل الإعداد فقط؛ لا يقيس دقة قانونية ولا ينفذ استدلالًا مدفوعًا. التشغيل الأول بعينة غير سرية هو اختبار الخدمات الفعلية.

## ٤. العقد الجديد

غلاف النقل يبقى متوافقًا، لكن نسخة سير العمل المطلوبة تغيرت:

```json
{"protocol":"mizan.workflow.v1","workflow":{"version":"egypt-rag-2.1.0","toolSlug":"disputes"}}
```

الطلب يحتوي نسخة التخصص وتعليماته وبصمته ومعرف الطلب، نطاق المستخدم المشتق، معرفات المستندات، مقتطفاتها النصية، النصوص القانونية المسموحة، التاريخ والقواعد، وسياسة البحث. هذه النسخة لا ترسل الملفات الأصلية الثنائية أو كل تخصيصات المكتب أو مفاتيح الخدمات. يجب رفض إصدار غير معروف؛ لا رجوع تلقائي للتحليل القديم.

المستقبل يرجع بصمة التخصص وسجل تجهيز الذاكرة والسياق، والنتيجة وعناصرها ومراجعها، ومعرفات النصوص المختارة وإصدار الذاكرة وأحداث العقد واستهلاك التوليد. المنصة تفحص مخطط البيانات والمعرفات والاقتباسات والتبعيات مرة أخرى، ثم تجمع النتيجة محليًا. سجلات المستقبل ليست دليلًا تشفيريًا على أنه نفّذ المراجعة الدلالية؛ السيرفر الذي تسمح له جزء موثوق من نظامك.

يكتب المستقبل ردًا واحدًا بصيغة جيسون إلى المخرج القياسي ثم يغلق. أي سجل نصي في ذلك المخرج يفسد البروتوكول. المعالج المرفق يستورد محرك المسارات نفسه، ولا ينفذ أوامر قادمة من النماذج.

## الحدود والتشغيل

المنصة تفرض مهلة كلية ٢٤٠ ثانية، واتصال السيرفر ٢٣٥، والمعالج ٢٢٠، والمستقبل يوقف نفسه بعد ٢٣٠. المهلة ليست نظام مهام خلفية. الرد بحد ١٫٥ ميجابايت. كل خادم له اتصال واحد متزامن في نسخة التطبيق، ولا توجد إعادة إرسال تلقائية أو استئناف بعيد.

طلبات خدمات السيرفر تستخدم قائمة عناوين آمنة واتصالًا مشفرًا. لو موديلك على عنوان محلي غير مشفر، ضعه خلف واجهة مشفرة خاصة مسموحة لهذا السيرفر؛ لا تعطل فحص العنوان في التطبيق. ذاكرة التضمين والترتيب على السيرفر مشفرة ومعزولة بالنطاق وتحتاج حماية نسخها الاحتياطية مثل المنصة.

استبدال المستقبل القديم مطلوب. المعالج القديم ذي الطلب الواحد محفوظ للرجوع إلى مصدر النسخة الأصلية، لكنه لا ينتج عقد النتيجة المصري ولا يصلح لهذه الأدوات الجديدة.
